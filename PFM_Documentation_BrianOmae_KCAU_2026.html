1. Project Overview

The Personal Finance Manager (PFM) is a web-based application designed to help individuals manage their personal finances effectively. The system enables users to track income and expenses, set budgets per category, and monitor progress towards savings goals — all through an intuitive, mobile-friendly interface.

The application is built as a single-file HTML application connected to a Supabase backend, ensuring real-time data persistence and secure user authentication without requiring complex server infrastructure.

5. Key Features

  • Secure user registration and login via Supabase Authentication
  • Real-time data persistence — all data saved to PostgreSQL database
  • Row Level Security (RLS) — each user sees only their own data
  • Interactive charts: spending trend, budget vs actual, goal progress
  • Category filter chips for quick transaction browsing
  • CSV export for spreadsheet use
  • PDF report generation via browser print
  • Fully mobile-responsive with bottom navigation bar
  • Notification bell and profile settings panel

6. System Architecture

Frontend: Single-file HTML application (app.html) with embedded CSS and JavaScript. No build tools or frameworks required — runs directly in any modern browser.

Backend: Supabase provides a PostgreSQL database, RESTful API (auto-generated), and JWT-based authentication. The app communicates with Supabase via the official JavaScript client library.

Hosting: Deployed on GitHub Pages — a free static site hosting service. The landing page (index.html) links to the main application (app.html).

Security: Row Level Security (RLS) policies on all database tables ensure users can only read and write their own data. API keys used are the public anon key, which is safe for client-side use when RLS is enabled.
